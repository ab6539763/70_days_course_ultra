# 《苍穹》企业级智能体中台——70天成长课程

本课程以一名转行工程师陈铭在蓬远科技参与"苍穹企业级智能体中台"从0到1研发、迭代、测试、部署的真实工作节奏为主线,把"零基础大模型应用开发70天培训课程"的全部技术知识点,融入一个连续70天、环环相扣的企业级项目成长故事中。

## 目录结构

- `00-bible/`:世界观与写作规范"圣经"文档,包含人物设定、公司与产品信息、技术栈与工程规范、逐日故事线对照表(beat sheet)、单日撰写执行手册、原始课表参考。**在阅读任何一天课件前建议先读这里。**
- `stage1-python-basics/`:第一阶段 Day1-14,Python编程基础(Sprint 0:新人内训)。
- `stage2-llm-theory-prompt/`:第二阶段 Day15-24,大模型原理与Prompt工程、Web基础(Sprint 1:苍穹0.1版)。
- `stage3-langchain-rag/`:第三阶段 Day25-38,LangChain与RAG开发(Sprint 2-3:海纳制造集团项目)。
- `stage4-agent/`:第四阶段 Day39-50,Agent智能体开发(Sprint 4-5:祺瑞集团项目)。
- `stage5-finetune-deploy/`:第五阶段 Day51-57,模型微调与部署(Sprint 6:御风金融项目)。
- `stage6-flagship-career/`:第六阶段 Day58-70,旗舰项目与职业发展(Sprint 7:寰宇集团项目 + 苍穹1.0发布 + 陈铭晋升)。

## 阅读建议

按天数顺序阅读效果最佳,每篇课件末尾的"明日预告"会自然引导到下一篇。

## 规模统计

- 课件天数:70/70(第1天至第70天,全部完成)
- 正文字数(不含代码):约258万字,每天均不少于30000字
- 代码总量:超过20万行(涵盖Python/FastAPI/前端HTML-CSS-JS/Docker/YAML/Shell/SQL等),分布在70篇课件的"代码实战"板块中
- 每篇课件均包含:需求文档、架构设计图、流程图、示意图(均为Mermaid图)、分时段课堂笔记、完整注释代码、【旁白】解读、课后作业与详细参考答案、明日预告(或全书回顾)
- 三大阶段项目 + 一个毕业设计(旗舰项目)均已落地:
  1. 命令行多轮对话AI助手(Day14)
  2. 海纳制造集团企业知识库问答系统(Day38)
  3. 多Agent智能办公助手(Day50)
  4. 寰宇集团全域智能体平台 / 苍穹1.0(Day58-70)
